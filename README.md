# language-trainer

مدرّب المهارة الآلية (سرعة الاستدعاء) — صفحة ثابتة + بيانات JSON في هذا المستودع.
Claude هو "الدماغ": يقرأ التقدّم، يقرّر خطة اليوم، ويكتبها هنا. الصفحة فقط تعرض وتدرّب.

## الملفات
| الملف | الدور | من يكتبه |
|---|---|---|
| `index.html` | الصفحة (تقرأ `words.json` و`today.json` من GitHub) | ثابت |
| `data/words.json` | كل الكلمات (بدون تكرار) | Claude عند رفع مستوى جديد |
| `data/progress.json` | تقدّم كل كلمة + سجل الجلسات + الإعدادات | Claude (بعد كل جلسة) |
| `data/today.json` | خطة اليوم (30 سؤالاً) | Claude (عند «اليوم») |
| `tools/plan.py` | يبني خطة اليوم | — |
| `tools/apply_results.py` | يطبّق كود الجلسة على التقدّم | — |

## الإجراء اليومي (لـ Claude)
**1) المستخدم يقول «اليوم»:**
1. اجلب `data/words.json` و`data/progress.json` (عبر GitHub API، الحالة الحقيقية دائماً — لا تعتمد على ذاكرة المحادثة).
2. `python3 tools/plan.py words.json progress.json YYYY-MM-DD > today.json` (التاريخ من ساعة الجهاز: أداة user_time_v0).
3. ارفع `data/today.json` (commit)، ثم **اقرأه من GitHub مرة ثانية وطابقه** قبل أن تقول إنه جاهز.
4. قل للمستخدم يفتح الصفحة.

**2) المستخدم يلصق كود جلسة** (يبدأ بـ `v1|`):
1. `python3 tools/apply_results.py progress.json today.json "<الكود>" > new_progress.json`
   (يرفض الكود إذا تاريخه ≠ تاريخ الخطة، أو طوله خاطئ، أو سبق تطبيقه).
2. ارفع `data/progress.json` (احتفظ بـ sha الحالي)، ثم اقرأه وطابقه.
3. لخّص للمستخدم: الدقة، أضعف نوع تمرين، وعدد كلمات ستعود غداً.

## صيغة كود الجلسة
`v1|التاريخ|<حرف النمط+نتيجته لكل سؤال>|<زمن كل سؤال بعُشر الثانية>`
- الأنماط: r استدعاء، v ترجمة عكسية، d إملاء سمعي، f قراءة سريعة.
- النتيجة: 1 صحيح، 0 خطأ/انتهى الوقت، x متروك.

## قواعد القرار
- أولوية: كلمات دقتها < 70% ثم المستحقة الأكثر تأخراً، ثم كلمات جديدة (A1 قبل A2، أنواع متداخلة)، ثم الأقدم تدريباً.
- لا تكرّر نفس نمط التمرين لنفس الكلمة مرتين متتاليتين؛ لا يتكرر نفس النمط في سؤالين متتاليين.
- التكرار الموزّع (إجابات صحيحة متتالية → المراجعة بعد): 0→1 يوم، 1→2، 2→4، 3→7، 4→14، 5+→30. الخطأ يُرجع الكلمة ليوم واحد.
- الوقت يضيق 0.5ث (حد أدنى 3ث) بعد 3 جلسات ≥90% في النمط، ويتسع 0.5ث إذا نزلت الدقة تحت 60%.

## رفع كلمات مستوى جديد (دمج بدون تكرار)
- المعرّف: `en:<الكلمة بحروف صغيرة>`؛ المعنى الثاني لنفس الكلمة `~2`, `~3`...
- إذا تقاطعت ترجمة السطر الجديد (بعد توحيد الألف وإزالة التشكيل وتقسيمها على `/` و`،`) مع كلمة موجودة ⇒ **دمج** في نفس البطاقة (تُضاف المصادر والفئات، ولا يُلمس التقدّم).
- إذا لم تتقاطع (مثل open فعل «يفتح» و open صفة «مفتوح») ⇒ بطاقة منفصلة.
- لا تعدّل معرّفات موجودة أبداً (التقدّم مرتبط بها).

## أمان
- المستودع **عام**: لا تضع فيه أي مفتاح أو بيانات شخصية.
- مفتاح الوصول (fine-grained، مستودع واحد، Contents فقط) يُعطى لـ Claude في المحادثة فقط، ويُلغى من GitHub عند الانتهاء.
