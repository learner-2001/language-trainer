# language-trainer — «بوابة الانطلاق»

مدرّب المهارة الآلية (سرعة الاستدعاء) للمفردات. صفحة واحدة تعمل بنفسها، وهذا المستودع هو قاعدة بياناتها.

**الرابط:** https://learner-2001.github.io/language-trainer/

## كيف يعمل
1. تفتح الصفحة فتقرأ الكلمات من `data/words.json` (وتحتفظ بنسخة على الجهاز لتعمل بلا إنترنت).
2. تبني خطة اليوم بنفسها (التكرار الموزّع)، وتدرّبك بأربعة أنماط: استدعاء، ترجمة عكسية، إملاء سمعي، قراءة سريعة.
3. **تقدّمك يُحفظ على جهازك تلقائياً بلا أي مفتاح.** هذا هو الوضع الافتراضي ولا ينتهي.
4. المزامنة مع GitHub اختيارية: تفيد إن أردت نفس التقدّم على جهاز آخر أو إضافة مستويات جديدة. إذا فُعّلت تُرسل الصفحة التقدّم بعد كل جلسة، وإن انتهى المفتاح أو انقطع الإنترنت تستمر على جهازك وتُرسل كل شيء عند تجديد المفتاح.

لا حاجة إلى Claude في الاستعمال اليومي.

## تطبيق أندرويد
- يُبنى داخل GitHub نفسه (GitHub Actions) من نفس الصفحة، ويظهر ملف `Gate.apk` في قسم Releases: https://github.com/learner-2001/language-trainer/releases/latest/download/Gate.apk
- داخل التطبيق: الكلمات مرفقة فيعمل بلا إنترنت، والنطق من محرّك هاتفك الأصلي، والتقدّم يُحفظ في التطبيق، وزر الرجوع يسأل قبل إنهاء الجلسة، والنسخة الاحتياطية عبر قائمة المشاركة.
- لبناء نسخة جديدة: شغّل صفحة الرفع (`upload-gate.html`) فهي ترفع الملفات وتشغّل البناء وتعرض زر التحميل. أو غيّر محتوى `build-trigger.txt` أو شغّل «Build Android APK» يدوياً من تبويب Actions.
- يُوقَّع كل بناء بنفس المفتاح (`app/gate-release.keystore`) فيُثبَّت التحديث فوق القديم وتبقى نتائجك. هذا مفتاح توقيع شخصي للتحديث فقط، وليس مفتاح دخول إلى حسابك.
- إن غيّرت ملفات الصفحة الأساسية فالصفحة على الويب تتحدّث لوحدها، أما التطبيق فيحتاج بناءً جديداً ليحمل التعديل.

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | الصفحة كاملة (الخطة، التدريب، الحفظ، لوحة التقدّم، استيراد الكلمات) |
| `manifest.webmanifest`, `sw.js`, `icon*.png/svg` | التثبيت كتطبيق وفتح سريع بلا اتصال |
| `app/` | مشروع التطبيق: إعداد Capacitor، توليد الأيقونة وشاشة البداية، التوقيع |
| `.github/workflows/build-apk.yml` | يبني `Gate.apk` داخل GitHub وينشره |
| `build-trigger.txt` | تغييره يبدأ بناءً جديداً |
| `data/words.json` | كل الكلمات بلا تكرار |
| `data/progress.json` | نقطة البداية للتقدّم، وتُحدَّث فقط إن فعّلت المزامنة |
| `tools/apply_results.py` | أداة للمطوّر تطبّق كود جلسة على ملف تقدّم |

## مفتاح المزامنة (اختياري)
- من github.com: Settings ← Developer settings ← Fine-grained tokens ← Generate new token.
- Repository access: مستودع واحد فقط (`language-trainer`). Permissions: **Contents: Read and write** فقط.
- Expiration: اختر **No expiration** (التوثيق الرسمي يسمح بها ما لم تمنعها سياسة منظمة). إن لم تظهر فاختر Custom بعد نحو سنة.
- يُلصق في الإعدادات ← «المزامنة بين الأجهزة». يبقى في متصفح ذلك الجهاز فقط ولا يُكتب في أي ملف.
- المستودع **عام**: لا تضع فيه مفاتيح ولا بيانات شخصية.

## النسخة الاحتياطية
- بلا مفتاح يعيش تقدّمك في ذاكرة المتصفح، فإن مُسحت بيانات الموقع ضاع. من الإعدادات ← «نسخة احتياطية» نزّل ملفاً، واسترجعه متى شئت على أي جهاز.
- تذكّرك الصفحة بنسخة جديدة كل 14 يوماً إن لم تفعّل المزامنة.

## إضافة مستوى جديد
الإعدادات ← «إضافة كلمات»: الصق الكلمات بأي صيغة (`word — ترجمة`، أو سطر بعد تاب، أو `word = ترجمة`)، اختر المستوى، راجع المعاينة ثم احفظ.
- الكلمة الموجودة تُدمج ولا يُمسّ تقدّمها. المعنى المختلف لنفس الكلمة يصير بطاقة مستقلة `~2`.
- لا تُعدَّل معرّفات موجودة أبداً لأن التقدّم مرتبط بها.

## قواعد التدريب
- الأولوية: الكلمات المستحقة الضعيفة (دقة أقل من 70%) ثم باقي المستحقة، ثم كلمات جديدة (A1 قبل A2 وتتناوب الأنواع)، ثم الأقدم تدريباً.
- لا يتكرر نفس النمط في سؤالين متتاليين، ولا تُدرَّب الكلمة بالنمط نفسه مرتين متتاليتين.
- إجابات صحيحة متتالية 0، 1، 2، 3، 4، 5 أو أكثر تعني مراجعة بعد 1، 2، 4، 7، 14، 30 يوماً. الخطأ يُرجع الكلمة إلى يوم واحد.
- الوقت يضيق 0.5 ثانية (حدّ أدنى 3) بعد 3 جلسات متتالية ≥ 90% في النمط، ويتسع 0.5 ثانية (حدّ أقصى 12) إذا نزلت الدقة تحت 60%.

## أداة الطوارئ (للمطوّر)
`tools/apply_results.py` تطبّق كود جلسة (صيغة v2) على ملف تقدّم، وتبقى مطابقة تماماً لمنطق الصفحة (الاختبارات تقارن بينهما). لا تحتاجها في الاستعمال العادي.
